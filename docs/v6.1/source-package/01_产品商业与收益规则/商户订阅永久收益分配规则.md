# 商户订阅永久收益分配规则

## 适用收入

本规则适用于商户支付的 898 元、1,980 元及以后新增的乐趣宝订阅套餐。算力包、代金券交易抽佣、硬件、定制开发和第三方代收费用分别计算，不进入本规则。

## 可分配收益

系统按商户、订阅订单和服务月份计算：

```text
可分配收益
= 当月订阅实际到账
- 当月及追溯退款
- 支付手续费及对应税费
- 该商户实际发生的 AI 成本
- 该商户实际发生的云服务成本
- 该商户实际发生的第三方接口成本
- 该商户实际发生的消费奖励成本
- 合同明确允许扣除的其他直接成本
```

未使用的 AI 额度不能当作成本。总部工资、办公室租金、通用研发费用、品牌费用和无法对应到具体商户的支出不能在分配前临时扣除。

可分配收益最低为零。普通经营亏损不让商务人员倒欠平台。已结分润对应的商户退款、拒付或重复支付需要按原单冲回。

## 分配比例

| 收益方 | 比例 |
| --- | ---: |
| 原始商务人员 | 70% |
| 尚智招商综合体公司 | 10% |
| 乐趣生活运营主体 | 20% |

比例作用于每月可分配收益，不直接作用于商户支付总额。

## 永久收益权

商务人员首次登记有效商机并完成签约后，系统把收益权绑定到商户法律主体。收益权没有自动到期日。

- 商户续费、升级或降级套餐，原商务人员继续取得 70%。
- 商务人员离开日常服务岗位，收益权仍然存在。
- 商务人员的数据访问权限可以结束，收益权不能因此被系统自动删除。
- 商户暂停付费期间不产生收益，恢复付费后继续计算。
- 同一法律主体重新注册、换门店或更换联系人，不能借此绕过原收益权。
- 欺诈、伪造商机、重复登记和法院或仲裁要求可以暂停收益，必须保留证据和审批记录。
- 转让收益权需要原权利人、新权利人和总部三方确认。

## 计算状态

每月账单依次经过：预估、成本待齐、待复核、锁定、可结算、已支付、冲回。

商务人员可以查看到账金额、每项成本、规则版本、70%金额、历史冲回和付款记录。无权修改成本或账本。

# 商务人员商户归属权规则

## 归属对象

商户归属以法律主体为主，以统一社会信用代码为首选识别项。个体工商户没有统一社会信用代码时，使用实名主体、证照编号和门店证据共同判断。

一个商户只能有一条有效的原始商务收益权。多人共同开发时，可以在 70%内部登记多人比例，合计必须等于 70%，不再增加额外层级。

## 有效商机

商务人员必须提交商户名称、主体或门店证据、有效联系人、首次沟通时间和下一步安排。只有手机号码而没有商户证据，不算有效商机。

系统检查统一社会信用代码、手机号、门店地址和历史合同。发现重复时进入归属争议，不允许先签约后补归属。

## 收益权与服务权分离

原商务人员长期拥有约定的收益权，但不因此长期拥有以下权限：

- 查看消费者名单；
- 导出商户订单；
- 查看商户支付账户；
- 修改商品、价格、退款规则或员工权限；
- 代表商户发布小程序或公开资料。

商务人员协助交付时获得限时、限商户、限动作的权限。交付结束后自动收回。

## 争议和转让

争议处理保存双方证据、审核人、处理理由、生效时间和旧规则快照。任何人不得直接改数据库归属字段。

收益权转让使用独立协议。转让只影响未来结算，除非协议明确处理历史未结金额。

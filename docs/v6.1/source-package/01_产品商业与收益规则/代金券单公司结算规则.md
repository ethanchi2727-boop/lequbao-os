# 代金券单公司结算规则

代金券原有业务规则继续执行：单池子、暂停定拨、用户主动选择用券、ZERO 和 COMMISSION 商家模式、按订单原价抽佣、奖励档位、加速池、两年有效期、退款冲正、负额度和规则版本全部保留。

取消旧的科技公司 15%、销售公司 15%、结算公司 70% 公司间分配。新订单只记录一个平台结算主体。该主体统一收取商家佣金、发放消费者和商家奖励、管理加速池、处理退款冲正并完成对账。

历史订单仍按成交时规则版本保存旧主体分配结果，不能修改历史流水。迁移时把旧主体记录标记为历史资料，不把三家公司余额简单合并成一条无法追溯的数字。

商务人员的订阅收益权不参与代金券抽佣。代金券收益、订阅收益和算力包收益使用三套独立账本和结算单。

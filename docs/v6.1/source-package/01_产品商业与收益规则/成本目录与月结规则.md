# 成本目录与月结规则

## 可以扣除的直接成本

- 模型调用、图像生成、语音识别和向量检索的实际采购成本；
- 该商户使用的云存储、带宽、消息和任务执行成本；
- 微信、短信、地图、GEO、ISV 和支付接口的实际费用；
- 对应订阅订单的支付手续费和可明确计算的税费；
- 该商户消费奖励由平台承担的实际金额；
- 商户合同中提前写明、能提供凭证的其他直接成本。

## 不可以扣除的成本

- 尚智、乐趣生活或乐趣宝的通用人员工资；
- 办公室、差旅、招商会和品牌宣传；
- 没有商户、账单或服务月份对应关系的估算费用；
- 套餐标称额度中未实际使用的部分；
- 为了降低分润而临时增加的内部管理费。

## 成本入账

每条成本包含商户、服务月份、成本类型、供应商、数量、单价、金额、凭证、来源事件和是否可分摊。共享云资源按已公开的分摊规则计算，规则改变只影响新月份。

月结时先收齐第三方账单。无法及时取得的成本可以使用经财务批准的暂估值，下月必须按实际金额补差。暂估、补差和原因对商务人员可见。

## 对账

订阅实际到账、直接成本、可分配收益和三方收益合计必须勾稽一致。出现一分钱差异也不能进入支付状态。

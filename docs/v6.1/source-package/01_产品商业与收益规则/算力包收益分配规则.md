# 算力包收益分配规则

## 净利润

```text
算力包净利润
= 算力包实际到账
- 退款及拒付
- 上游模型和算力采购成本
- 支付手续费及对应税费
- 该算力包直接产生的第三方费用
```

净利润最低为零。退款对应已结收益时，按原订单和原规则冲回。

## 没有区县服务商

| 收益方 | 比例 |
| --- | ---: |
| 乐趣宝 | 50% |
| 商务人员 | 30% |
| 尚智招商综合体公司 | 20% |

## 存在区县服务商

| 收益方 | 比例 |
| --- | ---: |
| 乐趣宝 | 50% |
| 商务人员 | 30% |
| 尚智招商综合体公司 | 10% |
| 区县服务商 | 10% |

区县服务商必须在算力包购买前处于有效授权状态，并与商户区域匹配。以后补登记区县服务商，不追溯改变已经锁定的订单。

# 安全上线基线

## 一、身份与会话

- 商家负责人、平台管理员、财务和发布操作开启多因素验证。
- 访问令牌短时有效，刷新令牌可撤销并绑定设备风险；退出、改密、离职和角色撤销后会话失效。
- 登录、切换租户、敏感操作和支持访问记录审计。
- 登录和验证码接口按设备、账号、IP 风险和租户限流，错误信息不泄露账号是否存在。

## 二、应用与接口

- 所有写接口使用服务端权限、租户、资源和状态校验。
- 金额来自服务端商品和规则快照；禁止相信前端金额。
- 订单、支付、退款、核销、发布、奖励使用幂等键和乐观锁。
- 上传文件校验类型、大小、内容和恶意文件，下载使用短时签名地址。
- 富文本和用户内容输出编码，防止脚本注入；管理端启用安全响应头。
- 回调验签后再解密和处理，原始请求受控保存并去重。

## 三、基础设施

- 开发、测试、预发布和生产账户、网络、数据库、对象存储和密钥分离。
- 数据库不暴露公网；生产连接最小权限，应用角色没有建表、超级用户或 `BYPASSRLS`。
- 备份加密、跨故障域保存，并定期做恢复演练。
- 依赖锁定版本并生成软件物料清单；高危漏洞未处理不得发布。
- 管理入口限制来源和设备风险，平台支持使用单独身份。

## 四、监控和告警

必须监控：登录异常、跨租户拒绝、权限变更、批量导出、退款和发布峰值、支付回调延迟、奖励账不平、死信、插件熔断、密钥读取、数据库慢查询和审计失败。

安全日志与业务日志分开保存。P0 安全告警立即冻结相关高风险写操作，但尽量保留查询、申诉和导出入口。

## 五、上线前证据

- 威胁分析和数据流图已评审
- 跨租户单元、集成和渗透测试通过
- 角色矩阵与真实接口权限一致
- 支付、退款、奖励和结算对账通过
- 回调验签、重放和幂等测试通过
- 插件越权和出网限制测试通过
- 客户导出、更正、撤回、删除流程通过
- 备份恢复和不可逆迁移演练通过
- P0/P1 告警和值班联系人有效

上述任一关键证据缺失，按《停止发布条件》处理。

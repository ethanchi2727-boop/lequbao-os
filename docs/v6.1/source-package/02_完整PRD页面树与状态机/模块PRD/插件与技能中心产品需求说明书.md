# 插件与技能中心产品需求说明书

## 模块目标

插件提供一项可独立授权和停用的能力。技能提供一套可重复执行的方法。AI 工作台和一键交付可以调用它们，但不能绕过权限、套餐和人工确认。

首发只上架平台自有或平台审核通过的插件与技能。第三方开发者自行发布、定价和结算不在首发范围。

## 插件要求

每个插件必须登记名称、提供方、用途、适用角色、所需权限、输入、输出、费用、数据去向、超时、重试、停用影响和支持联系人。

插件状态包括草稿、测试中、待审核、已上架、已停用和已下架。已安装商户受到下架影响时，系统提前通知并给出替代处理。

涉及外部账号的插件使用商户授权，凭证加密保存。页面只显示凭证尾号、有效期和授权范围，不能显示完整密钥。

## 技能要求

每个技能登记目标、适用行业、输入资料、执行步骤、使用插件、人工确认点、成功标准、失败处理和预计用量。

技能执行前显示会做什么、会访问哪些数据、是否产生费用和哪些动作需要确认。执行结束后生成结果和下一步。

平台可从成功的商户做法中整理技能，但必须去除客户隐私、商户专属资料和不可转让内容。未测试的做法不能直接上架给全部商户。

## 安装和授权

商户管理员选择安装。系统检查套餐、行业、依赖插件、费用和权限。缺少依赖时先列出处理步骤，不自动购买。

高风险权限按用途分别授权。读取订单不等于可以退款，读取客户资料不等于可以导出，生成内容不等于可以发布。

## 执行和计费

每次执行保存调用者、商户、输入摘要、插件版本、技能版本、用量、费用、结果和错误。含外部写入的任务使用幂等键。

付费插件在执行前显示计费单位和预计费用。失败是否收费按插件规则处理，账单能追溯到具体执行记录。

## 一键交付的关系

一键交付是乐趣宝的总任务。它可以调用小程序上传插件、GEO 检查插件、通知插件和行业开通技能。

用户可以停用某个非必需插件，但不能把一键交付拆成若干互不相干的购买项。套餐交付所需的基础插件由平台统一管理。

## 安全规则

- 插件按商户和任务发放最小权限。
- 外部回调验签并防止重复处理。
- 日志隐藏密钥、身份证、手机号和支付信息。
- 删除、发布、退款和权限修改必须人工确认。
- 插件失败不能把总任务标记为成功。
- 停用后撤回凭证和后台任务。

## 验收标准

1. 安装前能看到权限、费用和数据去向。
2. 读取订单权限不能调用退款接口。
3. 插件停用后，后台定时任务停止且凭证不可继续使用。
4. 技能更新后，历史执行仍能找到原版本。
5. 一键交付能显示每个插件步骤的结果，但仍是一条总任务。
6. 首发页面没有第三方自行上架和自行收款入口。

# 平台运营与渠道管理产品需求说明书

## 模块目标

平台总部在一个后台管理商户、合作伙伴、套餐、交付、用量、账单、分润、模板、插件、风险和服务质量。渠道合作伙伴只查看自己有权服务的商户和分润。

## 商户管理

平台人员可按地区、行业、套餐、状态、负责人、开通阶段、用量和风险筛选商户。

商户详情显示合同、门店、人员、交付、用量、账单、服务记录、投诉和续费。客户资料和订单明细按岗位单独授权，不能因为是平台人员就默认全部可见。

## 渠道管理

渠道档案包括主体、地区、合同、负责人、客户保护规则、分润规则、结算账户、服务能力和状态。

商机登记后检查重复主体、电话和门店。客户归属变更保存原归属、新归属、原因、审批和生效时间。

渠道人员可发起商户交付和查看所负责商户进度。不能修改平台套餐、绕过审批减价、授予高价插件或导出消费者名单。

## 分润与结算

系统按净实收、分润比例、退款观察期和冲回规则生成结算明细。渠道能查看计算过程和对应订单。

平台财务审核后生成结算单。退款、坏账和争议可冲回后续金额，但必须指明原订单和原因。

## 套餐与用量管理

平台配置套餐价格、门店、账号、用量、插件、通知和文件空间。修改配置要选择只影响新合同，还是按约定影响存量商户。

运营可查看 AI 实际成本、用量异常和高耗用任务。商户端只显示服务用量，不显示采购成本。

## 交付和服务质量

平台查看各地区的签约、资料完成、授权、审核、发布、培训、30 天活跃、投诉和续费情况。

交付停滞时能定位等待商户、等待微信审核、平台处理失败或人员未跟进。不能把所有延迟都算到技术团队。

## 风险管理

风险列表包括异常登录、批量导出、权限扩大、退款异常、奖励滥用、重复核销、插件失败、AI 错误回答和商户资质到期。

每个风险项有等级、负责人、截止时间、处理记录和结果。高风险操作支持暂停商户相关能力，但已有订单和售后仍按规则处理。

## 经营看板

总部看板至少展示净实收、在服商户、开通完成率、活跃率、续费率、退款率、单店变动成本、AI 成本、渠道分润和支持工时。

每个指标能下钻到商户或订单明细。统计口径和更新时间固定展示，不能只给没有来源的大数字。

## 验收标准

1. 渠道只能看到自己被授权服务的商户。
2. 套餐配置修改有审批和生效范围。
3. 分润能追溯到净实收、退款和原订单。
4. 高耗用商户能定位到具体任务和插件。
5. 商户停用时不会阻断已有订单和售后处理。
6. 总部指标能下钻，且展示统计口径和更新时间。

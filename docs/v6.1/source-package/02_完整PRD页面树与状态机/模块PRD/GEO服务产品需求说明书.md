# GEO服务产品需求说明书

## 模块目标

GEO 服务帮助商户把允许公开的信息整理准确，让网页、小程序和可接入的搜索服务更容易读取。服务重点是资料质量、可访问性、一致性和持续检查。

任何页面和销售材料都不能承诺第三方一定收录、一定排名靠前或一定带来客流。

## 资料范围

首发管理以下公开资料：商户名称、品牌、行业、门店地址、经纬度、电话、营业时间、服务范围、交通停车、商品和服务摘要、价格区间、团购、常见问题、图片、资质公开项和更新时间。

每个字段保存来源、负责人、最后确认时间、公开范围和有效期。

## 服务流程

### 建档

从商户资料中心读取公开信息。缺少地址、电话、营业时间或行业时，不允许显示健康状态正常。

### 一致性检查

检查乐趣生活、商家小程序、公开网页和已接入渠道中的名称、地址、电话和营业时间是否一致。

### 内容检查

检查描述是否清楚、图片是否可访问、关键页面是否有标题和结构化信息、团购是否过期、常见问题是否有可靠答案。

### 发布检查

对已接入的官方或授权接口提交资料。无法自动提交的渠道生成操作指引和人工待办。

### 可访问性监测

定期检查公开页面是否可打开、是否返回错误、关键字段是否仍存在。发现故障时通知商户和负责人员。

### 改进建议

按缺失字段、信息冲突、过期内容和消费者常问问题生成建议。建议说明修改什么、为什么和由谁确认。

## 健康评分

健康评分只反映平台可检查的资料质量，不代表外部排名。建议由完整度、一致性、时效、可访问性和问题响应五部分组成。

评分页面必须显示扣分原因和处理入口。不能只给一个分数。

## 变更处理

商户修改名称、地址、电话或营业时间后，系统列出受影响入口。自动更新只用于已授权接口。需要人工确认或第三方审核时，生成待办并记录结果。

信息更新失败后保留旧值和失败原因，不能把未成功发布的内容标记为已更新。

## 数据和合规

只有商户确认可公开的信息才能进入 GEO 服务。负责人手机号、身份证、结算账户和内部备注不得出现在公开资料中。

抓取或提交第三方平台信息时，必须遵守对方接口和访问规则。没有正式授权的渠道，不用模拟登录或规避限制。

## 关键指标

- 资料完整率。
- 不一致字段数量。
- 过期字段数量。
- 可访问页面成功率。
- 更新任务完成时间。
- 从可识别入口进入小程序的访问和订单。

入口访问数据只能说明可追踪来源的结果，不能推断所有第三方搜索效果。

## 验收标准

1. 健康分数能展开到具体字段和问题。
2. 修改门店营业时间后，系统列出受影响入口。
3. 外部提交失败不会显示成功。
4. 公开资料中不出现负责人身份证、结算账户和内部备注。
5. 页面固定展示“不保证第三方收录、排名或客流”的说明。
6. 未接入的渠道显示操作指引，不伪造自动提交结果。

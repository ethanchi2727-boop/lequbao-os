# 乐趣生活产品需求说明书

## 产品目标

乐趣生活是消费者日常购买和本地消费的统一入口。首页先让用户看见常买的生活商品、附近服务和正在发生的优惠，不增加重复导购步骤。

消费者可以从乐趣生活浏览多个商家，也可以从某个商家的独立小程序直接消费。两个入口共用账户关联、商品、订单、退款、会员和核销规则。

## 一级导航

### 生活

首页主区展示数字供应链和高频生活消费。内容顺序建议为位置与搜索、主 Banner、分类图标、常购入口、限时商品、附近服务和个性推荐。

Banner 整体可点击。图片内直接放清楚的主题文字、优惠信息和行动提示，不再添加“点进去看看”之类的重复文字按钮。

分类必须使用统一设计的彩色图标。首发分类建议包括米面粮油、酒水饮料、乳品早餐、家清纸品、水果生鲜、个护美妆、家庭服务和充值缴费。后台可按城市和供应情况调整。

### 商城

提供标准分类、搜索、筛选、商品列表、商品详情、规格选择、收藏、加购、结算、物流和售后。

### 生活圈

提供附近商家、地图与列表、团购、到店服务、预约、商家详情、购买须知、核销码和评价。

### 购物车

按商家分组展示商品。不同商家的订单分别结算。页面清楚显示运费、优惠、库存变化和失效商品。

### 我的

包含订单、团购券、售后、会员、消费奖励、优惠券、收藏、足迹、地址、发票、客服、消息、隐私和账号设置。

## 首页交互要求

首屏要让用户在 3 秒内看清当前城市、搜索入口、主要活动和高频分类。Banner、分类图标、商品卡和本地团购卡都使用统一圆角、间距和点击反馈。

按钮文字不能换行错位。价格、原价、单位和优惠信息必须有固定位置。卡片图片加载失败时显示同尺寸占位图，不让页面跳动。

首页推荐位说明推荐原因，例如“离你 800 米”“本周买过”“附近已售 326 份”。不能使用无法解释的夸张词。

## 搜索要求

搜索同时覆盖商品、商家、团购和服务。结果页按综合、距离、销量和价格排序，并支持类目、配送方式和可用时间筛选。

搜索无结果时，展示相近关键词、热门分类和附近商家。不得只显示空白页。

## 交易要求

消费者确认订单前要看到商家、商品、数量、优惠、配送或到店方式、退款规则、应付金额和预计时间。

支付结果必须以服务端查询为准。前端显示成功但服务端未确认时，进入确认中状态，不能重复创建订单。

到店团购生成核销凭证。核销前显示使用时间、适用门店、预约要求和不可用日期。核销后不能再次展示可用状态。

## 售后要求

消费者能从订单发起退款或售后，并上传图片和说明。系统根据订单类型显示可选原因和处理时限。

AI 客服可解释规则、查询进度和收集材料，但不能自行决定重大赔偿。争议进入人工处理，消费者能看见处理人、当前状态和下一步。

## 账号与隐私

首次使用只申请完成当前操作所需的权限。位置、手机号、订阅消息和相册权限按需申请，拒绝后仍提供手动城市、输入手机号或上传文件的替代方式。

消费者可查看授权记录、持续客户档案摘要、数据导出入口和删除账号入口。删除账号前先处理未完成订单、退款和余额类权益。

## 关键指标

记录首页到详情、详情到加购、加购到付款、付款到核销、售后和复购。来源要区分首页 Banner、分类、搜索、分享、门店二维码和 AI 客服推荐。

## 验收标准

1. 五个一级导航名称和顺序固定。
2. 首页不出现重复导购页和无意义的“点进去看看”。
3. Banner 整体可点击，文字与图片在常见手机宽度下不裁切。
4. 分类图标齐全，加载失败有占位图。
5. 跨商家购物车按商家拆单，优惠和运费计算可解释。
6. 团购购买、支付、核销、退款和评价能跑通。
7. 拒绝位置授权后，用户仍能手动选择城市和使用商城。

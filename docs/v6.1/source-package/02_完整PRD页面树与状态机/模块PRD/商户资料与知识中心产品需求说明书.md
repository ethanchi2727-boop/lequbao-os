# 商户资料与知识中心产品需求说明书

## 模块目标

商户资料与知识中心保存一份可信的经营资料，供小程序、AI 客服、GEO、员工和经营报告使用。商户修改一次，系统能指出哪些入口需要更新。

## 资料分类

- 主体资料：主体名称、统一社会信用代码、行业、资质和有效期。
- 品牌资料：品牌名、标志、主色、介绍和公开图片。
- 门店资料：地址、经纬度、电话、营业时间、交通、停车和服务范围。
- 商品与服务：名称、规格、价格、库存、适用门店、履约和售后规则。
- 经营规则：预约、核销、退款、改期、发票、会员和消费奖励。
- 客服知识：常见问题、标准回答、禁答内容、人工服务时间和负责人。
- 公开内容：允许用于小程序、公开网页和 GEO 的字段。

## 字段状态

每个重要字段保存草稿、待确认、已确认、已发布、已过期和已停用状态。还要保存来源、确认人、确认时间、有效期和公开范围。

AI 从文件提取内容后，只能进入待确认状态。没有商户确认的价格、退款和资质信息不能直接用于消费者回答。

## 导入方式

支持表单填写、标准表格导入、文件上传和 AI 辅助提取。导入前显示字段对应关系，导入后显示新增、更新、冲突和失败数量。

同一字段出现冲突时，系统不自动覆盖已确认内容。商户选择保留哪一项，并说明原因。

## 发布影响

商户修改关键资料后，页面显示受影响的小程序页面、AI 回答、GEO 内容和员工资料。商户可以逐项确认发布。

价格、库存和订单等实时数据由业务模块维护。知识中心只保存说明和规则，不复制实时数值作为长期答案。

## 知识测试

商户发布客服知识前，可以运行标准问题测试。测试显示回答、引用、实时工具结果、风险提示和是否需要人工。

每个行业提供默认测试集。商户也可把真实未解决问题加入测试集。测试失败不阻止保存草稿，但不能标记为已通过。

## 权限

主体、结算和资质资料只允许商户老板及被授权管理员查看。普通员工只能查看完成工作所需的公开资料和规则。

商务推广人员在交付期内可以协助填写，但商户必须确认主体、价格、售后和公开信息。服务结束或客户归属变化后，访问权限按规则收回。

## 验收标准

1. 文件提取内容默认是待确认，不直接发布。
2. 修改营业时间后能看见受影响入口。
3. 实时价格和库存不从旧知识文本回答。
4. 冲突字段必须由有权限人员选择，保留修改记录。
5. 普通员工不能看到主体证件和结算资料。
6. 知识测试能显示引用、工具结果和风险处理。

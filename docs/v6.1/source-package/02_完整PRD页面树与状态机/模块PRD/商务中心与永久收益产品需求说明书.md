# 商务中心与永久收益产品需求说明书

## 商务首页

首页显示今日待办、有效商机、待签约、待补资料、交付中、即将续费、当月可分配收益、70%预计收益、待结算、已支付和冲回。

## 商家开发

商务人员通过对话新增商机，也可以拍摄门店、发送名片或上传营业执照。Agent 自动查重并生成商机卡片。商机必须有下一步和保护状态。

## 报价与签约

系统只允许选择已发布套餐和授权折扣。报价单显示订阅价格、直接成本扣除说明、商务收益计算方式和商户服务内容。商务人员不能私下增加永久免费的高成本能力。

## 商户归属

签约前必须确定法律主体和原始商务人员。多人协作时登记 70%内部比例。归属权状态包括待核验、生效、争议、暂停、转让中和终止。

## 永久收益账户

商务人员查看：

- 每个商户当月实收；
- AI、云服务、第三方、支付、税费和消费奖励成本；
- 可分配收益；
- 本人 70%或内部约定比例；
- 暂估与下月补差；
- 待结、已结、冲回和累计收益。

每个数字都能查看来源订单和成本凭证。商务人员只能申诉，不能修改。

## 交付协助

商务人员从商户卡片发起一键交付。资料收集默认进入 Agent 对话。商家完成法律主体、支付、价格、售后和正式发布确认。交付结束后，商务人员临时数据权限自动收回，收益权继续存在。

## 续费

到期前 30、15、7、1 天提醒商务人员和商户负责人。续费成功沿用原收益权，不重新争夺客户归属。

## 总部管理

总部可以设置成本目录、收益规则版本、结算周期、暂估规则、争议处理人和付款账户。暂停或转让永久收益权必须双人审批并记录理由。

## 验收

- 同一商户不能同时产生两条有效原始收益权；
- 订阅升级和续费仍进入原商务收益账户；
- 数据权限到期不会删除收益权；
- 分配合计与可分配收益一致；
- 退款能追溯并冲回原结算单；
- 商务人员不能看到未授权的消费者数据。

# 组织权限与租户管理产品需求说明书

## 模块目标

公司、合作伙伴和商户共用乐趣宝登录体系，但数据必须按租户、组织、门店和角色隔开。一个人可以加入多个组织，权限不能跟着账号错误带到另一个组织。

## 组织类型

首发支持平台总部、渠道合作伙伴和商户三类组织。商户下设品牌和门店。平台总部可管理平台级配置，但查看客户明细仍需要岗位权限和业务原因。

## 成员和角色

用户通过手机号或平台支持的统一身份方式登录。加入组织必须接受邀请或经过管理员确认。

首发预置平台负责人、平台运营、平台客服、平台财务、商务推广人员、渠道管理员、商户老板、店长、商户客服、收银员、核销员和普通员工角色。

预置角色可以复制后调整，但商户老板、平台超级管理员和审计角色的关键权限不能被普通管理员扩大。

## 权限结构

权限分为页面访问、数据范围、具体动作和敏感字段四层。

数据范围至少支持本人、负责商户、指定门店、全部门店和组织全部。具体动作区分查看、新增、修改、删除、导出、审核、退款、发布、授权和配置。

敏感字段包括主体证件、结算账户、完整手机号、客户地址、人工备注和插件凭证。拥有页面访问不等于能查看敏感字段。

## 套餐和插件限制

权限只回答用户是否有权操作。套餐和插件还要回答商户是否购买了能力。接口必须同时检查权限、套餐、插件状态和用量。

套餐到期或插件停用时，系统保存原角色设置。续费恢复后可继续使用，不需要重新分配。但在停用期间不能通过旧链接或接口继续操作。

## 切换组织

顶部组织选择器显示当前组织、角色和最近访问。切换后清空页面缓存、搜索条件、文件上下文和 AI 会话中的组织数据。

后台任务绑定创建时的组织和门店。用户切换组织不会改变正在执行任务的归属。

## 授权和回收

员工离职、合作伙伴退出或商户更换服务人员时，管理员可立即停用账号和撤回会话。系统同时停止该用户创建的个人访问令牌，并把未完成任务转交给新负责人。

高权限角色设置有效期和二次确认。临时查看客户资料到期后自动收回。

## 验收标准

1. 用户从商户 A 切到商户 B 后，页面、搜索、文件和 AI 上下文全部刷新。
2. 只有查看订单权限的员工不能退款。
3. 只有查看客户列表权限的员工不能导出完整手机号。
4. 套餐停用后，旧接口令牌不能继续调用收费能力。
5. 员工停用后，未完成任务能转交且历史操作仍可追溯。
6. 后台任务始终保留创建时的组织和门店归属。

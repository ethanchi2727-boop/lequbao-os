# 唯一开发基线

本目录是乐趣宝与乐趣生活的唯一开发依据。

开发人员先读取本目录，再读取 `01_产品商业与收益规则` 至 `07_Trae_Codex立即开发`。`80`、`81`、`82` 保存旧业务、旧 UI 和代金券原件，用于继承和核对，不能覆盖本目录的新决定。

产品只有两个：

- 乐趣宝：公司总部、商务人员、招商公司、区县服务商、商家老板、店长、员工、客服和财务使用的统一 AI 工作台。
- 乐趣生活：消费者使用的生活消费小程序。

原销售宝改成乐趣宝中的商务中心。原经营宝改成商家经营中心。原城市服务商工作台改成区域运营中心。原 MiniApp Factory 改成小程序交付引擎。GEO OS 改成 GEO 服务。Skill Network 分成技能、插件和工作流后进入 Harness。

商家资料不再要求用户先填传统表单。用户通过文字、语音、照片和文件与 Agent 对话，Agent 自动识别、整理和补充。传统表单只用于核对和人工纠错。

商户订阅收入先扣除该商户实际发生的直接成本，再按商务人员 70%、尚智招商综合体公司 10%、乐趣生活运营主体 20% 分配。商务人员的 70% 没有自动到期日，只要原商户持续付费就持续产生。

算力包按净利润分配。无区县服务商时，乐趣宝 50%、商务人员 30%、尚智招商综合体公司 20%。有区县服务商时，尚智和区县服务商各 10%。

代金券原有抽佣、消费者奖励、商家奖励、加速、退款冲正和负额度规则不变。科技公司、销售公司、结算公司 15%／15%／70% 的公司间分配取消，改由一个平台结算主体统一处理。

当前历史效果图只用于对照。正式前端以 `03_UIUX原型效果图与设计资产` 中的新原型、页面合同和设计变量为准。

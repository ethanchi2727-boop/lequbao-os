# 开发读取顺序

1. 阅读 `唯一开发基线.md`。
2. 阅读所有产品、收益、成本和代金券规则。
3. 阅读页面树、模块 PRD 和状态机。
4. 阅读 UI 设计系统、可运行原型和效果图。
5. 阅读数据结构、接口、事件、权限和安全要求。
6. 阅读测试门禁和停止发布条件。
7. 最后执行 `07_Trae_Codex立即开发/开发主指令.md`。

涉及钱、代金券、奖励、退款、余额、结算、永久收益权或历史数据迁移时，开发人员不得根据页面文案自行推断规则。发现冲突必须停止相关开发并登记问题。

每个功能必须同时交付页面、接口、数据库、权限、审计、异常处理和测试。只完成页面不算完成。

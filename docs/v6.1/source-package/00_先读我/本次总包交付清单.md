# 本次总包交付清单

## 一、已经冻结的事

- 产品只保留两个对外品牌：乐趣宝和乐趣生活。
- 乐趣宝是统一 B 端 AI 工作台。总部、商务、尚智、区县服务商、商家、店长、客服和财务通过角色和插件使用同一底座。
- 乐趣生活是 C 端小程序。一级栏目是生活、商城、生活圈、购物车、我的。
- 商家资料改为 AI 对话建档。传统表单只做修正和兜底。
- 商户订阅净收入按商务 70%、尚智 10%、乐趣生活 20% 分配。商务份额在商户持续订阅时持续有效。
- 算力包按是否有有效区县服务商，使用 50/30/20 或 50/30/10/10 规则。
- 代金券保留原计佣、奖励、加速、退款冲回和负余额规则；取消多公司拆分，由一家公司结算。

## 二、可直接供开发读取的产物

- 307 个二至六级页面节点，其中 197 个可执行叶子页。
- 197 个叶子页均定义路由、角色、目标、组件、操作、接口域、验收和八类状态。
- 14 张 V6.1 关键效果图和一套可运行 HTML/CSS/JS 原型。
- 16 类彩色立体生活图标、3 类消费 Banner 素材和按钮状态规范。
- PostgreSQL 15+ 基线架构 73 张表，包含租户、支付、退款、核销、奖励、插件、AI 建档和收益结算。
- V6.1 独立迁移脚本、37 个 OpenAPI 路径、46 个领域事件、38 个产品埋点。
- 15 个角色、51 个权限控制项、143 条验收测试。

## 三、自检结果

静态契约、JavaScript 语法、页面数量、权限、事件、测试和效果图数量已通过总包门禁。

当前环境没有传入一次性 PostgreSQL 测试库，所以 SQL 真实执行、支付沙箱、微信审核和企业微信回调联调仍是开发环境的上线阻断项。

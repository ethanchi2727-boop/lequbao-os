# 开发唯一主指令

只使用本总包 `00` 至 `07` 作为现行开发规则。`80`、`81`、`82` 用于继承旧能力和核对代金券原件，不得覆盖现行决定。

第一阶段先完成多租户、角色权限、商户主体、商务永久收益权、成本目录、订阅账单、算力包净利润、代金券账本和审计。没有真实数据库测试前，不接生产支付。

第二阶段完成 Harness 适配、AI 对话建档、企业微信内部入口、一键交付、小程序发布、GEO、AI 客服和人工接管。

第三阶段完成乐趣生活五栏目、商城、本地团购、购物车、订单、核销、退款、会员、代金券和消费者客服。

前端开发必须读取页面树、页面合同、设计变量和可运行原型。历史效果图没有展示的状态不能删除。所有页面必须包含加载、空、错误、无权限、断网、处理中和恢复状态。

涉及金额、奖励、收益权、退款和结算的代码必须测试整数金额、边界、幂等、并发、重复回调、乱序、部分失败、补偿、对账、租户隔离和迁移回滚。

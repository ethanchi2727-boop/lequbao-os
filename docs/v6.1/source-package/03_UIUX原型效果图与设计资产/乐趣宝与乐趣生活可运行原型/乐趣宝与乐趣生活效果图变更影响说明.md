# 乐趣宝与乐趣生活效果图变更影响说明

## 变更目标

在已确认的消费者端视觉基础上，补齐开发前必须看清的四个关键界面：商家小程序发布流程、在线 AI 客服、员工人工接管、商户月度价值报告。同时修正一键交付中的产品边界文案。

## 直接影响

- `app.js`：新增效果图视图与客服、发布、价值报告组件；修正文案。
- `styles-v3.css`：新增上述视图的独立样式，不改动乐趣生活既有主视觉。
- `index.html`：加载新增样式并去掉版本号标题。
- `render.mjs`：改为从当前目录渲染并新增截图清单。
- `verify.mjs`：增加关键文本、禁用词和截图数量校验。

## 间接影响

- 一键交付结果中的“小程序”必须明确为商家自有 AppID 的标准模板实例。
- 企业微信只表示员工内部通知入口，不表示自动接管外部联系人或客户群。
- AI 客服主会话发生在商家小程序，人工在乐趣宝客服台接管。
- GEO 只展示资料发布、可访问性与监测结果，不展示排名保证。

## 不变范围

- 乐趣生活五个一级栏目及其消费者视觉方向不变。
- Harness 工作台的空白、对话、任务模式与右侧“任务/成果/来源”结构不变。
- 本轮效果图不加入飞书、AI 盒子、个人微信助手。

## 验证

- 每个视图均能由静态渲染器生成完整页面。
- 所有新增截图尺寸与清单一致。
- 全局不得出现“飞书”“永久记忆”“保证排名”“接管个人微信”等错误承诺。
- 原有消费者端四组效果图继续生成并通过校验。

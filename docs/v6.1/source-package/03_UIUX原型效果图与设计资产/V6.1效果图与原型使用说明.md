# V6.1效果图与原型使用说明

## 一、目录

- `关键效果图_V6.1`：14 张经过尺寸校验和人工视觉检查的效果图。
- `乐趣宝与乐趣生活可运行原型`：HTML、CSS、JavaScript、图片素材和渲染脚本。
- `Harness交互基线_仅验收控件`：Harness 控件和页面状态验收矩阵。

## 二、V6.1 主要原型路由

| 参数 | 内容 |
|---|---|
| `?view=bao-intake` | AI 对话建档 |
| `?view=bao-business` | 商务中心与永久收益 |
| `?view=bao-revenue` | 收益月结与成本明细 |
| `?view=bao-delivery` | 一键交付与 Harness 任务 |
| `?view=bao-miniprogram` | 商家小程序发布 |
| `?view=bao-service` | AI 客服与人工接管 |
| `?view=bao-ecosystem` | 插件与技能生态 |
| `?view=bao-mobile-v61` | 乐趣宝移动端 |
| `?view=life-home-v61` | 乐趣生活鲜活首页 |
| `?view=life-tabs-v61` | 五个一级栏目 |
| `?view=life-kit-v61` | Banner、立体图标和按钮精修 |
| `?view=life-details` | 商品、团购、结算和 AI 详情 |

## 三、打开方法

直接用浏览器打开 `index.html`，或在该目录启动任意静态文件服务，然后在地址后加上表中参数。

例如：

```text
index.html?view=bao-intake
index.html?view=life-home-v61
```

## 四、重新渲染效果图

进入原型目录后执行：

```bash
node render-v6.1.mjs
```

只渲染指定页：

```bash
node render-v6.1.mjs bao-intake life-home-v61
```

渲染脚本会检查图片尺寸和非空内容。渲染通过不等于已完成浏览器兼容、真机触控和动态数据验收。

## 五、开发时不能做的事

- 不能用历史效果图覆盖 V6.1 结构和金额规则。
- 不能把乐趣宝做成生鲜小程序配色。
- 不能把乐趣生活改回冷淡、稀疏的工具风。
- 不能省略 Harness 的任务、成果、来源、后台任务、执行模式、上传和恢复状态。
- 不能在 Banner 上再放“点进去看看”之类的多余按钮。

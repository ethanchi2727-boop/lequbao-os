# 乐趣宝Harness交互验收规范

## 1. 首页只有三种形态

### 新对话

PC 为左侧空间与历史导航加中心输入区。右侧“任务与成果”不出现。

移动端为单栏输入，侧栏使用抽屉。

### 普通对话

回答、引用、工具摘要和轻量确认留在消息流内。没有复杂成果时，不占用第三栏。

### 复杂任务

产生后台任务、多个步骤、成果文件、来源集合或待确认写操作时，右侧出现“任务、成果、来源”三个页签。关闭右栏不停止任务。

移动端把右栏变为底部抽屉，抽屉可半屏和全屏。

## 2. 必须保留的区域

- 左侧：新建任务、搜索、授权空间、业务入口、最近会话、身份卡。
- 顶部：保存状态、执行模式、后台任务、分享、更多菜单。
- 中间：用户消息、AI消息、工具过程、引用、结果卡片、人工确认。
- 输入区：附件、联网、技能、插件、语音、斜杠命令、引用、排队发送。
- 右侧：任务进度、成果预览、来源、风险确认、暂停、恢复、重试、回滚。

“工作区”不得同时指左侧和右侧。左侧叫“空间与历史”，右侧叫“任务与成果”。

## 3. 消息操作

每类消息按权限支持：

- 复制。
- 编辑后重发。
- 重新生成。
- 继续。
- 停止。
- 赞同或反馈问题。
- 查看来源。
- 查看执行轨迹。
- 展开工具参数和结果。
- 对失败步骤安全重试。

高风险写操作不能只靠模型文字确认，必须进入正式确认卡，重新检查身份、数据范围、对象状态、风险级别和幂等键。

## 4. 身份卡

左下角固定显示姓名、当前组织、门店或区域、当前角色。

身份卡至少包含：

- 可切换组织和门店。
- 角色与数据范围。
- 可用插件和套餐权益。
- 企业微信绑定状态。
- 通知设置。
- 持续客户档案和隐私入口。
- 主题、语言、安全设备和退出。

切换身份后，菜单、知识库、工具、数据范围和未完成任务必须重新校验。

## 5. 八类页面状态

所有主要组件和页面都要处理：

1. 默认。
2. 加载中。
3. 空数据。
4. 局部错误。
5. 无权限。
6. 功能停用或套餐不含。
7. 成功。
8. 可恢复失败。

恢复态必须告诉用户失败在哪一步、已经保留什么、下一步能做什么。不能只显示“系统错误”。

## 6. 响应式与可用性

- PC 以 1440×900 为基准，支持 1280 宽度。
- 移动端覆盖 360、375、390、430 宽度。
- 关键触控区至少 44×44 像素。
- 文字缩放 200% 时，关键操作不能被遮挡。
- 键盘可完成新建、搜索、发送、关闭弹层、切换焦点。
- 颜色不是唯一状态提示，必须有文字或图标。
- 深色模式不是简单反色，要重新检查对比度、图表和浮层。

## 7. 与业务页的关系

Harness 是统一任务外壳，销售、交付、商家后台、客服、财务、经营分析都是授权业务入口。

业务页既能被 Agent 调用，也能手动打开。Agent 不能绕过业务服务直接写数据库；业务服务必须再次判断租户、角色、状态和金额规则。

## 8. 验收材料

- 68 项 Harness 控件逐项通过。
- 三种形态各有 PC 浅色、PC 深色、移动浅色、移动深色截图。
- 关键控件具备八类状态或明确不适用说明。
- 普通对话不会错误出现右栏。
- 复杂任务关闭右栏后继续运行。
- 人工接管客服后 AI 停止对外回复。
- 切换租户后不会残留前一租户的菜单、数据或缓存。

# 小满首页 V2 视觉方向确认稿

本轮只重构首页视觉与交互结构，未覆盖现有开发总包。

## 冻结方向

- 小满是第一工作入口，不再使用传统经营看板作为首页。
- PC 为三栏 Harness：会话历史 / 对话执行 / 按需展开的任务与成果工作区。
- 移动端为 Chat-first：对话、执行轨迹、成果卡片、插件抽屉与完整输入工具栏。
- 新建对话、搜索历史、附件、联网、技能、插件、语音、执行轨迹、成果预览、来源和人工确认均在首屏可发现。
- “今日工作”固定右栏已取消；右栏只在任务执行时显示任务、成果、来源和审批。
- 尚智使用 Apple 式极简、玻璃层次、柔和蓝紫 Aurora 与大留白。
- 开普使用既定的白绿日间、深绿侧栏、黑绿夜间 Agent 风格。
- 两套系统共用交互骨架，但业务插件和数据权限严格隔离。

## 首页行为建议

- 首次进入：显示空白新对话与能力建议。
- 再次进入：恢复最近一个未结束工作；“新建对话”始终固定在左栏或移动端右上角。
- 右工作区默认折叠；任务产生执行轨迹、成果或待确认动作时自动展开，用户可随时关闭。

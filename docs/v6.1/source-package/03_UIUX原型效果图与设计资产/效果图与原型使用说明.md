先打开“关键效果图”目录，重点看四张新补页面：

1. 乐趣宝_PC端_商家小程序发布.png
2. 乐趣宝_PC端_AI客服与客户.png
3. AI客服_消费者与员工移动端.png

这些页面是视觉和关键流程基线，不是可直接上线的前端工程。开发时要用真实路由、组件、接口、权限和状态替换静态内容。

## 两套基线怎么用

“乐趣宝与乐趣生活可运行原型”是本项目最终品牌和业务方向。

“Harness交互基线_仅验收控件”只用于核对 DeepSeek Harness 的完整控件、空白/对话/任务三种形态、PC/移动、浅色/深色和异常状态。该目录保留参考包原有名称和示例内容，不代表乐趣宝最终品牌，不得照搬业务文案、角色或数据。

开发验收时必须同时满足：

- 视觉和业务以本项目效果图为准。
- Harness 控件和状态数量不得少于基线。
- 生产页面不得出现参考项目名称。
- 所有真实数据必须经过乐趣宝租户权限和服务端接口。

## 图片范围

本轮共 12 张关键效果图：

- 乐趣宝 PC：一键交付、小程序发布、AI客服、价值报告、经营工作台、插件与技能。
- 乐趣宝移动端：一键交付、消费者与员工客服。
- 乐趣生活：生活首页、五个一级栏目、关键内页、视觉细节板。

完整二级到六级页面不靠 154 张手工效果图逐页重复，而由《页面树.csv》《页面规格索引.md》、设计系统和组件状态统一约束。重要交易、授权、客服、发布和售后页面应在开发冲刺中补交可交互高保真稿。

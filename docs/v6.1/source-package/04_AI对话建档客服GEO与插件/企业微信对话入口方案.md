# 企业微信对话入口方案

企业微信是乐趣宝 Agent 的一个入口，不保存另一套商户资料和会话事实。

## 首版能力

- 员工通过企业微信内部应用打开乐趣宝安全会话；
- 在会话中发送文字、图片、文件和语音；
- 查看 Agent 的识别结果、缺项问题和任务进度；
- 点击安全卡片进入乐趣宝 H5 完成主体、价格、支付、退款和发布确认；
- 接收交付失败、资料待确认、客服待接管和续费提醒。

## 不做的事情

- 不让 AI 冒充员工回复个人微信好友；
- 不自动读取员工所有外部联系人和群聊；
- 不把企业微信机器人当成消费者客服主入口；
- 不在普通消息中直接展示完整证照、支付账户和消费者资料。

## 身份和权限

企业微信用户先绑定乐趣宝用户。每次消息带组织、用户、会话和商户上下文。没有商户权限时只能发起申请，不能因为知道商户名称就读取资料。

文件从企业微信进入后保存原始来源、发送人、时间和消息编号。下载失败、文件过期和重复发送都需要可恢复处理。

# AI运行与受控Agent方案

## 运行原则

乐趣宝里的 AI 不是拿到全部权限后自由操作。每个 Agent 都在明确的商户、角色、任务、工具、步数、费用和时间范围内运行。

DeepSeek Harness 负责对话、计划、工具调度和任务状态。乐趣宝负责租户、权限、审批、知识、业务规则、审计和费用限制。模型不能直接连接数据库，也不能直接拿长期第三方密钥。

## 运行上下文

每次 Agent 运行都要带以下信息：

- 商户、品牌、门店和当前组织。
- 操作者、角色和临时任务权限。
- 工作流、任务和当前步骤。
- 允许使用的插件与工具。
- 可读取的知识范围和顾客授权范围。
- 最大步骤、工具次数、模型费用和截止时间。
- 是否允许生成草稿、写入、发布和资金动作。

缺少商户或操作者范围时，任务不得开始。

## 计划与执行分开

Agent 先生成结构化计划。策略服务检查每一步的工具、权限、风险和费用。通过检查后才执行。

执行时，每个工具仍要独立验权。不能因为整个计划通过，就让后续工具跳过检查。

## 动作分级

### 自动执行

读取公开资料、检索本商户知识、生成草稿、检查格式、汇总报表和查询任务状态。

### 执行后通知

建立内部待办、标记知识缺口、更新未公开草稿和发送不含顾客敏感资料的内部提醒。

### 执行前确认

修改商品和团购、发送顾客消息、导入客户资料、提交小程序审核、公开发布 GEO 内容和批量任务。

### 双重确认

退款、赔付、奖励资金、删除数据、导出顾客资料、修改权限、正式发布小程序和生产环境回退。

## 工具防护

工具输入使用固定结构，不接受模型拼接任意 SQL、脚本和网址。网络插件只能访问批准域名。文件先做类型、大小、病毒和内容检查。

写入工具使用幂等键。工具超时后先查询实际状态。结果未知时停止后续动作并请求人工处理。

## 运行限制

- 对话型任务最多 8 个计划步骤。
- 标准后台任务最多 12 个计划步骤。
- 一键交付通过工作流拆分，不受单个对话请求持续时间影响。
- 单个步骤默认 30 秒超时，长任务进入后台队列。
- 同一可重试错误最多自动重试两次。
- 高风险动作不自动重试。
- 达到费用或工具次数上限后停止，并说明已完成和未完成事项。

## 上下文和记忆

短期上下文只服务当前会话。长期使用的是有权限、有来源和有期限的知识与持续客户档案。模型不能把全部聊天内容自动写入客户档案。

顾客档案、商户知识、平台规则和行业模板分开存储。检索前先过滤商户和门店，再做相似度匹配。

## 人工暂停点

Agent 到达确认步骤时，任务状态改为 `WAITING_APPROVAL`。页面展示将要执行的动作、影响对象、金额或公开范围、依据和可撤销方式。

确认令牌只对当前动作、当前版本和短时间有效。任务内容变化后，旧确认自动失效。

## 审计

每次运行保存用户输入、计划摘要、工具参数摘要、知识来源、模型和规则版本、审批、工具结果、费用和最终状态。敏感字段按规则遮盖。

审计记录可以回答“谁在何时让哪个 Agent 对哪个商户做了什么，依据是什么，结果是什么”。

## 失败降级

模型不可用时，客服转固定提示和人工队列。后台任务保留状态并等待恢复。任何降级都不能放宽权限，也不能把未知结果写成成功。

- 商品权限、门店数据范围、幂等、乐观锁、改价/时段强确认、审计、埋点和 Outbox 同事务执行；商品事件数据库禁止修改和删除。
- E5 会员域：新客/活跃/沉睡/高价值四分层、标签、消费时间线、终身价值、平均客单、可解释复购预测与流失风险。

- 会员权限、门店数据范围、幂等、乐观锁、L2 强确认、审计、埋点和 Outbox 同事务执行；会员事件与时间线数据库禁止修改和删除。
- E6 销售宝今日工作台：今日任务、逾期提醒、已完成、本月签约、预计佣金、保护期线索和重点商机统一编排。
- 可解释 AI 下一步建议：按 CRM 阶段、时效、保护期、来源、体检分和争议状态排序，固定保存策略/模型版本、推荐分、依据与“不自动触达/不修改阶段”护栏。
- 销售任务投影：CRM 下一步动作按版本生成任务；动作变化后旧任务自动归档，完成和稍后提醒均要求乐观版本、幂等键与业务原因。
- 销售任务事件、CRM 时间线、审计、埋点与 Outbox 同事务执行；任务事件数据库禁止更新和删除，任务严格继承线索 SQL 数据范围。
- E6 商家 CRM：真实 SQL 数据范围内的线索列表、关键词/阶段/来源/跟进时机组合筛选、负责人、保护期、争议、跟进次数和最近跟进聚合。
- 商机地图采用有来源、置信度和版本的坐标事实；未定位线索保留在列表但不伪造坐标，演示本地参考坐标与生产地图服务边界已在界面明确标注。
- 销售宝商家一级页可从列表或地图精确进入既有详情、合同授权、归属申诉和不可变跟进时间线，返回后跟进次数、下一动作和逾期指标实时收敛。
- E6 商家归属治理：销售只能发起同城转移申请，城市经理/总部基于申请版本与线索版本审批；批准后负责人、30 天保护期、活动任务和原负责人观察协作关系同事务切换。
- 归属申诉与转移互斥冻结，经理可基于证据通过或驳回；通过后保护期重新起算，所有申请、裁决和协作变更均进入不可修改的归属证据链。
- E6 业绩与佣金中心：签约收入、续费收入、交易分成、月度目标、预计佣金、已结佣金与冲正统一由服务端读模型计算，销售和城市负责人分别获得个人/团队数据范围。
- 目标采用只追加版本修订；佣金采用只追加账本，财务结算新增流水把预计金额迁移至已结，退款/撤销新增负向流水同步冲正业绩和佣金，原流水、规则快照、原因与证据永久保留。
- 销售宝今日页的本月签约和预计佣金已改为读取业绩账本，不再使用前端或临时比例推算；销售端无权修改支付、代金券和结算事实。
- E6 团队成长中心：城市—小队组织树、个人/团队五维绩效卡、能力成长、同城排行、职级路径、培养计划与只追加人才证据统一进入销售宝真实页面。
- 晋降级采用城市负责人发起、总部人才校准审批的职责分离；每次只允许相邻一级变更，强确认、乐观锁与幂等同时生效，审批前不改变成员职级。
- 绩效卡固化结果、商机、过程、质量、合规五维和模型版本；培养计划固化目标、动作、成功标准、截止时间与阶段签到，绩效卡、职级事件和培养事件均由数据库禁止篡改。
- E6 AI 销售助手：拜访准备、话术、异议模拟、会议纪要、下一步建议与价值提案统一进入 375px 真实工作台；所有输出绑定 CRM/体检/跟进/合同证据及模型、提示词、策略版本。
- AI 草稿默认零外部动作；会议纪要只有经销售强确认才写入 CRM，异议模拟按共情、证据、合规和收口评分，草稿版本、模拟轮次与 AI 事件均由数据库禁止篡改。
- E7 城市服务商本地增长中心：城市线索池、搜索与阶段筛选、销售负载、强确认负责人调整、AI 体检、四档套餐、折扣审批、电子合同和六类独立授权统一进入真实工作台。
- 新增 `CITY_PROVIDER_ADMIN` 城市级角色：可管理本城市销售与交付主链，不具备全国配置、MiniApp/Skill 发布或销售 AI 私域权限；负责人调整同步迁移未完成任务但不静默修改保护期与下一步。
- 城市线索分配事件固化前后负责人、操作者、原因、线索版本与规则版本，数据库禁止修改删除；体检、价格、合同和授权复用 E1 核心域，避免城市工作台产生第二套规则。
- E7 九阶段交付中枢：签约自动建立唯一案件、城市负责人和 168 小时总 SLA；待采集、资料采集中、小程序生成中、商家确认、审核中、已上线、GEO 服务中、Skill 生成中、已交付全部由四个权威领域实时投影。
- 城市交付页面提供九阶段分布、案件队列、负责人、下一步、阶段停留、SLA 风险、四域来源状态和统一证据链；主操作携带精确 ID 深链入网、Factory、GEO 或 Skill 工作区。
- 交付案件建立事件由数据库禁止修改删除，历史已签约/已交付商家自动幂等回填；查询在 SQL 层执行租户和城市隔离，销售角色不能读取城市交付池。
- E7 交付工单中心：八类服务端模板、同城负责人负载、优先级、截止时间、SLA 状态、附件和商家确认进入统一 Work Order OS；创建、调整、开始、提交、退回恢复和确认均具备幂等、乐观锁与强确认边界。
- 附件保存原始二进制和 SHA-256，商家确认保存姓名、身份、意见、工单版本和平台留痕人；附件、确认快照与工单事件均由数据库禁止修改删除。
- 新增 `CITY_DELIVERY` 演示交付身份和工单细粒度 RBAC：交付人员可以处理工单但不能代商家确认，城市管理角色负责创建、调整和确认，销售角色不能进入工单池。
- E7 SLA 自动升级：60 秒调度扫描真实工单截止时间，按超时 0/4/12 小时建立 L1 城市响应、L2 服务商介入和 L3 总部督办；跨级首次扫描按顺序补齐全部升级事实，重复扫描不重复通知。
- 负责人恢复计划采用强确认、幂等与乐观锁；持续超时会重新打开下一层处置，工单完成后系统自动关闭异常。发现、升级、确认和关闭事件均只追加，并生成明确为待连接器投递的 Outbox。
- 新增 SLA Control Room：城市异常队列、三级策略轨道、最长超时、升级对象、恢复计划、原工单深链和完整证据时间线统一进入 375px/桌面自适应页面。
- E7 续费经营中心：已签合同自动建立年度服务周期，30/15/7/1 天节点扫描跨级补齐提醒事实，重复扫描不重复投递；提醒明确写入待连接器 Outbox，不伪造短信或微信送达。
- 续费提案冻结已完成工单、GEO 健康分、在线 Skill 和已确认交易事实，并按套餐目录给出保持或升级建议；建议明确禁止收益、排名和续费结果承诺。
- 续费结果采用强确认、幂等与乐观锁；确认续费后按现行续费规则写入既有佣金账本，流失必须选择标准原因、记录事实，可挽回机会还必须留下下一动作。
- 新增 Renewal Revenue OS：城市续费漏斗、四段生命周期轨道、价值证据账本、套餐迁移提案、续费计佣、流失分析和只追加时间线统一进入 375px/桌面自适应页面。
- E7 城市经营驾驶舱：城市商家、活跃商家、确认服务收入、续费率、完整交付时长、Skill 可交易率、确认交易 GMV 和代金券启用率统一按 30/90/365 天冻结口径聚合。
- E7 城市收益结算中心：按月冻结签约、续费与交易事实及版本化分成规则；城市方申请调账、总部独立审批、等额发票核验、财务强确认结算形成职责分离闭环，完成后一次性追加不可改写账本并发布 `settlement.completed.v1`。
- 服务收入只读取签约/续费确认与冲正事实，GMV 只读取交易分成确认与冲正事实；进行中交付不进入时长样本，Skill 调用量不冒充交易结果，所有口径和数据新鲜度均在页面可解释。
- 新增 City Operating Intelligence：经营脉冲、周期对比、风险信号、商家网络钻取、行业结构、八项口径和六个权威域新鲜度统一进入 375px/桌面自适应页面；`provider.metrics.read` 仅授予总部和城市管理角色。
- E8 消费者端首段垂直切片：首页城市、消息未读、显式家庭身份、全局搜索及对应 H5/微信页面全部接入真实 API、数据库和共享契约。
- 消费者数据使用独立 `SELF` 范围；家庭身份不改变登录主体，切换动作具备乐观锁、幂等、审计、埋点和 Outbox，消息正文与家庭上下文历史受不可篡改约束。
- 消费者搜索只展示已发布、获平台展示授权、营业中且目录有效的真实内容；原始查询只进入本人私有历史，审计和埋点只保存 SHA-256 摘要，查询不进入 Outbox。
- 消费者 AI 文本会话接入真实 API 与数据库：最多返回 3 个已发布授权商家，文本原文不进入审计；订座只先生成 L2 草稿，明确确认后才创建零支付、待商家确认的真实订单。
- 消费者语音输入接入受限二进制上传、私有音频暂存、待连接器 Outbox、HMAC 签名回调、连接器事件幂等和失败状态；原音频在回调后立即删除，上传成功不冒充转写成功。
- 转写成功只生成本人可见、可编辑的待确认草稿；用户必须明确确认，且服务端只接受同一条已确认文本作为 `sourceVoiceInputId` 原子复用既有文本助手。转写原文不进入审计、埋点或 Outbox。
- 消费者图片输入接入 JPEG/PNG/WebP 受限上传、扩展名/MIME/魔数/尺寸基础校验、私有原图暂存、HMAC 签名识别回调、事件幂等及失败状态；成功或失败回调后立即删除原图。该边界不冒充真实图片识别连接器或恶意内容扫描。
- 图片识别成功只生成本人可见、可编辑的待确认描述；用户必须明确确认，且服务端只接受同一条已确认描述作为 `sourceImageInputId` 原子复用既有文本助手。原始识别描述不进入审计、埋点或 Outbox。
- 消费者门店详情已接入真实发布授权、营业状态、权威目录、实时 SKU 价格库存和可信位置事实；搜索、附近和助手推荐统一进入该页面。预约只展示规则范围内的真实槽位、剩余容量和时段覆盖价，并把日期限制在套餐有效期内；停售、过期或库存/容量不足时不伪造可售。
- 消费者核对价格和规则后只能建立含价格/规则/套餐版本快照的 `WAITING_CONFIRMATION` 套餐草稿；预约另固化不可变槽位 ID、版本、覆盖价和服务时间。此时不创建订单、不占库存/预约容量、不生成核销凭证、不发起扣款或支付连接器请求。
- 消费者可对套餐草稿执行独立强确认；服务端重验本人上下文、门店发布授权、Catalog/SPU、有效期、价格、规则/套餐/槽位版本及资源余量，并在单一事务中创建经营宝订单、不可变订单快照及有限库存或预约容量占用。毛额与优惠额保留原价语义，价格漂移或资源竞争会整体回滚。

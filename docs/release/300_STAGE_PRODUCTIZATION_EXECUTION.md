# 300 个真实开发阶段执行台账

## 阶段定义

本台账中的一个“阶段”必须同时具备明确范围、实际增量、定向验证和状态记录。单独读文件、运行一条已有命令、生成编号或重复同一检查均不计阶段。`300_CHECKPOINT_LIFE_CLOSURE.md` 中的 300 项属于机器检查点，不属于这里的开发阶段。

状态只能使用 `DONE`、`IN PROGRESS`、`PENDING` 或 `CONTROLLED`。受控环境、真实身份、真实支付、provider、微信真机和生产发布没有证据时不得写成 `DONE`。

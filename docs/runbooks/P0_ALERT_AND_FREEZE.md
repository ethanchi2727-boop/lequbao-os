# P0 alert and selective freeze

The deployment must inject a tested 24-hour on-call contact; the repository intentionally contains no personal contact. A P0 page is acknowledged within 5 minutes. Preserve reads, customer appeal and lawful export wherever isolation permits.

1. Record alert code, trace ID, first occurrence, affected tenants and current release manifest.
2. Activate only the flag named by `ops/alerts.yaml`; do not stop order or customer service because one GEO target or plugin failed.
3. For cross-tenant evidence, audit failure, unbalanced money or suspected secret access, freeze affected high-risk writes immediately and rotate the relevant service identity.
4. Preserve append-only evidence. Do not edit ledgers, callback receipts or audit logs.
5. Reconcile affected orders, payments, refunds, rewards and event delivery before reopening.
6. Reopen only with incident owner, security and finance approval where money or personal data is involved.

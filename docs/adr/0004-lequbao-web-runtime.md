# ADR-0004: 乐趣宝首个 Web 运行时

- 状态：接受
- 日期：2026-08-18
- 解决冲突：C-005

## 决定

PAGE-014 与 PAGE-175–178 先以一个依赖最小的响应式 TypeScript/JavaScript Web 应用交付，包名为 `@lequ/workbench-web`。PC 与移动 H5 共用同一领域状态、API 客户端、可访问语义和设计令牌；路由决定信息密度与现场动作，不复制业务规则。

此阶段不引入 React/Vue/UniApp。当前页面交互不需要组件框架，使用浏览器原生模块可避免在首个真实页面切片中同时迁移包管理器、框架和构建链。若后续页面复杂度需要框架，必须用新 ADR 说明迁移范围，并保持本包为唯一活跃实现。

## 边界

- 页面只调用 API，不直接读写数据库。
- 演示数据仅在显式 `demo=1` 时启用，视觉验收不得被误认为生产联调。
- 法律主体、支付、价格、退款、公开联系方式和发布影响继续走服务端确认接口。
- `dist/` 是可再生构建产物，不提交。

## 回滚

删除 `apps/workbench-web` 并回退本 ADR 即可；不影响 API、数据库迁移或历史数据。

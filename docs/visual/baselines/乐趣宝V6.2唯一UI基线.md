# 乐趣宝 V6.2 唯一 UI 基线

本文件是乐趣宝 PC 与 Mobile 的正式视觉依据。自 2026 年 8 月 25 日起，旧版蓝色 Harness、尚智小满页面和此前零散效果图不再作为乐趣宝开发参考。

## 一、产品气质

乐趣宝是商户、商务人员和交付团队使用的 AI 经营工作台。界面必须专业、可信、清爽、数据优先。它不是消费者商城，也不是满屏粒子和霓虹特效的科幻产品。

## 二、双端分工

PC 负责多任务、经营数据、项目交付和复杂上下文。Mobile 负责对话、确认、任务推进、经营提醒和收益查看。两端共享业务数据，不共享页面布局。

## 三、Mobile 五栏

底部固定为：对话、工作、任务、消息、我的。每一栏必须同时显示图形图标和短文字。图标必须使用 `assets/mobile-tabs` 中的正式图片资产，不得用“AI、商、时、消、我”等文字字符代替。

## 四、视觉语义

- 深墨石用于导航和高信任信息；
- 玉石绿用于品牌、完成、增长和主要操作；
- 冰川青用于连接和同步；
- AI 紫只用于智能体、AI 建议和自动生成；
- 琥珀橙用于等待确认和可恢复风险；
- 红色只用于失败、拒绝和发布阻塞。

## 五、开发门禁

新页面必须使用 PC 或 Mobile Theme Namespace，并继承共享 Layout 和 Components。页面中不得散落新增 Hex、RGB、阴影和圆角。未通过静态视觉契约、图片完整性、字体覆盖、尺寸检查和五张母版渲染，不得合并。
